## What it does

ETL Pipeline Monitor watches every job run across Airflow, dbt, Fivetran, and custom pipelines, predicting failures before SLAs break and ranking likely root causes so engineers fix the right thing first.

## Key features

- **Failure prediction** — runtime and error-pattern trends flag jobs likely to fail.
- **Root-cause ranking** — upstream vs downstream failure attribution across DAGs.
- **SLA tracking** — per-pipeline SLA burn-down with breach forecasts.
- **Cost visibility** — warehouse spend per pipeline and per run.
- **One-click runbooks** — remediation steps attached to recurring failure modes.

## Who it's for

Data platform teams running 50+ daily pipeline jobs who want fewer 3 a.m. pages.
